# 🤖 AI Chatbot (ChatGPT-Style)

A modern AI chatbot with a **ChatGPT-like interface**, built using **Streamlit** and powered by **Groq API (LLaMA 3)** for fast and intelligent responses.

## ⚙️ Run Locally

### 1. Clone repository

```bash
https://github.com/krishnacharan43/AI-chatbot.git
```

---

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

---

### 3. Set API Key

```bash
setx GROQ_API_KEY "GROQ_API_KEY"
```

Restart terminal after this step.

---

### 4. Run app

```bash
python -m streamlit run app.py
```
